# Text

**Layer 2 of 3.** Every token that colors words. Names start with `--color-text-`. Each one has registered contrast pairs against the surfaces it can sit on, in both themes.

<SemanticTable property="text" />

Use `text-primary` for what people must read, `text-secondary` for support, and the severity and link tokens for their jobs only. For the size and weight of text, see [Typography](?path=/docs/foundations-semantic-typography--docs).
